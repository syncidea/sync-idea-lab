# SIL-003 · Приведите имя к единому виду

**Easy · Java 21 · около 20 минут**

[Все задачи](../../../README.md#задачи) · [Как запустить проект](../../../docs/getting-started.md)

## Контекст

В учебном сервисе имя пользователя вводят вручную. Для поиска нужно одинаково обработать варианты с разным регистром и пробелами по краям.

## Контракт

```java
public static String normalize(String name)
```

Уберите пробельные символы по краям по правилам `String.strip()`. Затем переведите строку в нижний регистр независимо от языка системы. Внутренние пробелы, цифры и знаки сохраняются.

## Примеры

- `"  Alice-42  "` → `"alice-42"`
- `" Анна  ИВАНОВА "` → `"анна  иванова"`
- `""` или строка только из пробельных символов → `""`

## Требования

- `name == null` → `NullPointerException`.
- Результат зависит только от содержимого строки. Локаль операционной системы не должна менять его.
- Сохраняйте внутренние символы. Изменение регистра применяется ко всей строке.
- Доработайте [UsernameNormalizer.java](src/main/java/dev/syncidea/lab/names/UsernameNormalizer.java), сохранив сигнатуру метода.

## Граничные случаи

Пустая строка, табуляция, Unicode-пробелы по краям, кириллица и латинская `I` при турецкой локали.

## Критерии приёмки

- Краевые пробельные символы удаляются по правилам String.strip().
- Регистр меняется одинаково при любой системной локали.
- Внутренние пробелы и знаки сохраняются.
- Пустой ввод и null обрабатываются по контракту.
- Все открытые JUnit-тесты проходят.

## Ограничения

Используйте стандартный API строк. Проверка формата допустимого имени в задачу не входит.

## Подсказка

> [!TIP]
> Найдите перегрузку метода изменения регистра, которая принимает `Locale`. Подумайте, какая локаль не привязана к стране или языку.

## Усложнение

Для самопроверки примените нормализацию к уже нормализованной строке. Результат должен сохраниться.

## Запуск

Запустите команды из корня репозитория в PowerShell.

```powershell
.\mvnw.cmd -pl challenges/java-core/SIL-003-username-normalizer clean test-compile
.\mvnw.cmd -pl challenges/java-core/SIL-003-username-normalizer clean test
```

Первая команда проверяет, что код и тесты компилируются. Вторая запускает тесты.
До реализации ожидается `UnsupportedOperationException`. В Linux и macOS используйте `./mvnw`.
