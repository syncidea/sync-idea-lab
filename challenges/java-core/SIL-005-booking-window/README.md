# SIL-005 · Проверьте окно бронирования

**Easy · Java 21 · около 20 минут**

[Все задачи](../../../README.md#задачи) · [Как запустить проект](../../../docs/getting-started.md)

## Контекст

Переговорная доступна для бронирования в определённое время. Проверьте, начинается ли встреча внутри доступного окна.

## Контракт

```java
public static boolean contains(LocalTime opensAt, LocalTime closesAt, LocalTime time)
```

Верните `true`, если `time` находится в интервале `[opensAt, closesAt)`. Открытие входит в интервал, закрытие — нет. Если времена равны, окно пустое.

## Примеры

- Окно `09:00–17:00`, запрос `09:00` → `true`
- Окно `09:00–17:00`, запрос `12:30` → `true`
- Окно `09:00–17:00`, запрос `17:00` → `false`

## Требования

- Любой аргумент `null` → `NullPointerException`.
- `closesAt` раньше `opensAt` → `IllegalArgumentException`.
- Используйте полную точность `LocalTime`. Значение ровно на границе отличается от значения за наносекунду до неё.
- Доработайте [BookingWindow.java](src/main/java/dev/syncidea/lab/booking/BookingWindow.java), сохранив сигнатуру метода.

## Граничные случаи

Момент до открытия, обе границы, пустое окно, время за наносекунду до закрытия и неверный порядок границ.

## Критерии приёмки

- Время открытия включено, закрытия исключено.
- За наносекунду до закрытия окно открыто.
- Нулевой интервал пуст.
- Некорректные аргументы отклоняются.
- Все открытые JUnit-тесты проходят.

## Ограничения

Окно находится в пределах одного дня. Часовые пояса и интервалы через полночь не используются.

## Подсказка

> [!TIP]
> Проверьте начало и конец разными условиями. В одном случае равенство допустимо, в другом оно означает, что окно уже закончилось.

## Запуск

Запустите команды из корня репозитория в PowerShell.

```powershell
.\mvnw.cmd -pl challenges/java-core/SIL-005-booking-window clean test-compile
.\mvnw.cmd -pl challenges/java-core/SIL-005-booking-window clean test
```

Первая команда проверяет, что код и тесты компилируются. Вторая запускает тесты.
До реализации ожидается `UnsupportedOperationException`. В Linux и macOS используйте `./mvnw`.
