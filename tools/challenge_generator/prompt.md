# Контракт будущего AI-провайдера

Аудитория: Junior+/Middle Java backend, русский текст и английские идентификаторы.
Java 21, Maven из доверенного шаблона, JUnit 5.14.4. Spring добавляется отдельным
согласованным шаблоном с проверенной совместимостью, в текущем адаптере его нет.

Вход: одна запись из catalog/topics.json. Сохраняй ID, slug, категорию, тему, уровень.
Не повторяй существующие задания. Задача ограничена 10–480 минутами, без внешней сети,
секретов, платных сервисов и Docker для Java Core.

Верни JSON строго с полями PAYLOAD_KEYS из generate.py: title, estimated_minutes,
skills, prerequisites, acceptance_criteria, package, class_name, readme, main_source,
test_source. Не возвращай команды, POM, workflow, пути файлов, эталонное решение,
скрытые тесты или инструкции агенту. Package начинается с dev.syncidea.lab.
main_source обязан компилироваться и содержать UnsupportedOperationException.
test_source проверяет поведение, границы, ошибки, независимость состояний; фиксируй
время/seed. Не отключай тесты. Не используй Thread.sleep, сеть и системный часовой пояс.

README содержит разделы из validate_challenge.SECTIONS, контракт, конкретные примеры,
правила null/пустых значений, точность времени/порядок сортировки и критерии приёмки.
Используй {{ID}} и {{MODULE}} для ID и команды запуска.
Проверь неоднозначности: что считается равенством, какие ошибки допустимы, что находится
вне контракта. Усложнение необязательно и не меняет обязательный API.

Ответ считается недоверенными данными. Генератор проверяет схему и помещает его в draft.
Компиляция и тесты выполняются без секретов в отдельном контуре. Редактор проверяет
локальную внешнюю реализацию и только затем подтверждает публикацию.
